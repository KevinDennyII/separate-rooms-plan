# The Separate Rooms Plan

A playful one-page note for Strawberry Cupcake about what separate bedrooms would actually take.

Static HTML + photos. No build step.

## Local

```bash
open index.html
# or
python3 -m http.server 8080 --bind 0.0.0.0
```

## GitHub Pages

This repo deploys from the `main` branch root. After push, the site is at:

`https://<github-username>.github.io/separate-rooms-plan/`
